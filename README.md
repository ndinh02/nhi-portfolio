# Nhi Portfolio

Hi, I'm Nhi (Macaroonie). I design interfaces and websites, and I build them with AI-assisted no-code tools. This is my portfolio, built in code so it loads fast and is easy to skim.

It is a Vite + React + TypeScript site, hosted on Vercel. English is the main language, German is the second one.

## Run it

```bash
npm install
npm run dev
```

Other commands:

```bash
npx oxlint          # lint
npx tsc --noEmit    # type check
npm run build       # production build
```

## What's inside

- `src/` has the site code.
- `public/` has the images, face photos and videos.
- `agents/` has the step-by-step agent briefs I use to plan, write, build and check the site.
- `AGENTS.md` has the design brief: colors, fonts, tone and things to avoid.
