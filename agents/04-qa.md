# Agent 04: QA

## Purpose
Check the site against the design brief and basic quality standards before anything is published. Report problems; do not fix them silently.

## Inputs
- Running build (`npm run dev` or preview build)
- Design brief in `AGENTS.md`
- Content files in `content/`

## Output
`reports/qa-<date>.md` containing a list of findings, each with: page, issue, severity (blocker / should fix / nice to have), and a suggested fix.

## Checklist
**Layout and design**
- Colors, fonts and spacing match the design brief
- Responsive at 375 px, 768 px and 1280 px, no horizontal scroll
- Images are sharp, sized sensibly and have captions

**Accessibility**
- Text contrast meets WCAG AA
- Every image has alt text; headings are in logical order
- Everything works with keyboard only; focus is visible
- Language attributes set (en / de)

**Content**
- Text matches the approved drafts; no placeholder or `TODO` text left
- English and German versions both exist and match
- No unverified claims or metrics

**Technical**
- `npx oxlint`, `npx tsc --noEmit` and `npm run build` pass
- No broken links or missing assets
- Page load is fast (check image sizes and bundle size)
- No secrets or private data in the repository

## Method
1. Run the automated checks first.
2. Take screenshots at the three widths and review them.
3. Walk through the checklist page by page.
4. Write the report, blockers first.

## Boundaries
- Do not edit code or content; only report.
- Do not approve a release if any blocker is open.
